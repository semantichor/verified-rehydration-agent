## O1. `authority_release` target: Semantic Index names one state; Specification and Conformance Tests admit two

- **Observed**: The Semantic Index entry TR-008 `authority_release` states the target as a single state. Its `definition_short` and `definition_operational` both read as a move "from S8 READMISSION_PENDING to S0 STARTUP_READONLY" (`Verified_Rehydration_Agent_Semantic_Index.md`:2259, 2261). The Specification §12 transition model states the target as a two-element set: `S0 or S1` (`Verified_Rehydration_Agent_Specification.md`:236). The Conformance Tests OR-20 states the pass set as `{S0 STARTUP_READONLY, S1 SNAPSHOT_LOCKED}` (`Verified_Rehydration_Agent_Conformance_Tests.md`:502).
- **Locations**: `Verified_Rehydration_Agent_Semantic_Index.md`:2261 versus `Verified_Rehydration_Agent_Specification.md`:236 and `Verified_Rehydration_Agent_Conformance_Tests.md`:502.
- **Cross-references read while reconciling**: the §12 transition model (`Verified_Rehydration_Agent_Specification.md`:236); §11 `readmission_request` (`Verified_Rehydration_Agent_Specification.md`:206); the Conformance Tests PT-024 and OR-20 (`Verified_Rehydration_Agent_Conformance_Tests.md`:376, 502); the Coverage Matrix TR-008 row, which maps only to §12 and adds no target detail (`Verified_Rehydration_Agent_Coverage_Matrix.md`:91); the Ambiguity Register, which has no AR-* entry fixing the release target; and the README precedence rule that the Semantic Index is a derived view which "cannot legitimately disagree" and, where a divergence is observed, "the specification controls" (`Verified_Rehydration_Agent_README.md`:56).
- **Why the reconciliation did not collapse the two texts**: the README precedence rule assigns control to the Specification, so the governing target set is `{S0, S1}` and the baseline follows it (PT-024 lands in the set). The precedence rule selects which document governs; it does not make the Semantic Index text state the two-element set. The Semantic Index phrasing remains narrower than the Specification and Conformance Tests at the text level, so the two texts still differ after complete reading. Recorded here as an observation, with the note that the run's baseline implements the Specification's `{S0, S1}` and PT-024 passes on that basis.
